# ChatGPT Playwright Automation

A Python automation project using Playwright to connect to Chrome through the Chrome DevTools Protocol (CDP).

## Features

- Connects to Chrome using CDP
- Opens ChatGPT
- Sends a prompt automatically
- Reads the ChatGPT response
- Records the browser interaction
- Creates an MP4 video using FFmpeg

## Requirements

- Python
- Google Chrome
- Playwright
- FFmpeg
